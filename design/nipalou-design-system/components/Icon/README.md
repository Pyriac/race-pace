# Icon

Pictogrammes au trait (1,75 px, extrémités rondes, grille 24 px) dans l'esprit Lucide — substitution choisie faute de jeu d'icônes sur le site.

**Le consommateur fournit** : `name` (`arrow-right`, `clock`, `mountain`, `map-pin`, `users`, `flag`, `info`, `circle-check`, `triangle-alert`, `circle-x`), `size` (20 px dans le texte, 24 px seule), `title` pour une icône porteuse de sens (sinon elle est décorative et masquée aux lecteurs d'écran).

L'icône prend la couleur du texte (`currentColor`) : `ink-muted` dans les détails, la couleur du statut dans une notice. À éviter : une icône seule sans `title` sur un bouton, des émoji en guise d'icônes.
