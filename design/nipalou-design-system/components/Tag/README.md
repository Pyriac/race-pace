# Tag

Étiquette courte en pilule pour qualifier une course : label, points, catégorie, nouveauté.

**Le consommateur fournit** : un texte de un à quatre mots (`children`), un `tone`, éventuellement une `icon` de 14 px.

- `brand` : qualifications et labels fédéraux (« Qualificatif France 2027 »).
- `accent` : points UTMB Index / ITRA.
- `highlight` : nouveauté ou podium, avec texte `on-highlight`.
- `earth` : courses jeunes ; `info` : randonnées et informations pratiques ; `neutral` : le reste.

À éviter : plus de trois tags par carte, une phrase dans un tag, un tag cliquable (utiliser `Button` `ghost`).
