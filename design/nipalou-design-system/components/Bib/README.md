# Bib

Le dossard épinglé : numéro condensé sur papier, bandeau vert, quatre épingles — le clin d'œil au dossard 15 de l'ours.

**Le consommateur fournit** : `number`, `race` (ligne sous le numéro, ex. « 21 km »), `event` (texte du bandeau, défaut « Tour du Nipalou »), `size` (`md` 200 px, `sm` 128 px).

Le dossard reste en papier clair dans les deux thèmes (jetons de palette `terre-50`, `terre-900`, `sapin-700`) : la nuit, il ressort comme un dossard sous la frontale.

Usages : confirmation d'inscription, page « Vérifiez votre inscription », fiche coureur dans les résultats. À éviter : un dossard décoratif sans numéro réel, plus d'un dossard `md` par écran.
